Про наш проєкт

Даний веб-проєкт є частиною лабораторних робіт з дисципліни «Програмування на Java» (версія 2, лабораторна робота №1). Основна мета – ознайомлення з основами Spring Boot та демонстрація роботи зі статичними ресурсами.

Проєкт складається з кількох статичних сторінок:

  • Головна сторінка – містить кнопки переходу до інших розділів.
  • Про проєкт – інформація про мету та контекст виконання лабораторної роботи.
  • Сторінки учасників – персональні сторінки студентів із коротким описом, навичками та посиланнями на соціальні мережі.

Виконали: студенти групи ІО-35, 3-й курс. У рамках цього завдання ми створили невеликий сайт, де кожен учасник команди представив себе та свою роль у проєкті.

Використані технології:

  • Java, Spring Boot (starter-web)
  • HTML5 + CSS3
  • Flexbox для верстки
